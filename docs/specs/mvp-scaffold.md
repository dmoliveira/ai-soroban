# Original MVP Scaffold

This document records the original baseline. The current product surface is described in `product-spec.md` and `roadmap.md`.

## Original goal

Ship a useful public foundation quickly, then expand curriculum depth.

## Original included scope

- Astro static export and GitHub Pages compatibility
- base layout and navigation
- starter lessons and exercises
- one-at-a-time practice mode
- local progress dashboard
- support, about, and privacy pages

## Current status

The MVP is complete and has expanded into six levels, multiple training formats, adaptive planning, games, bosses, certified worksheets, responsive navigation, and automated local browser validation. New work should preserve the static/local-first constraints rather than treating this scaffold as the active roadmap.
